# Podcast TTS Skill - 使用指南

## 快速开始

### 基本用法

```
用 podcast-tts 处理 <脚本文件路径>，<角色音色配置>
```

### 示例

```
用 podcast-tts 处理 JimFan红杉分享.txt，旁白用原野，主持人用晓曼，Jim Fan 用苏哲
```

## 脚本格式要求

### 角色标记

使用 `【角色名】` 标记角色切换：

```
【旁白】
欢迎收听 AI 智识录...

【主持人】
首先，我非常荣幸...

【嘉宾】
谢谢大家...
```

### 格式规则

1. **角色标记独占一行**：`【角色名】` 必须单独一行
2. **使用中文方括号**：必须是 `【】` 而不是 `[]`
3. **角色名任意**：可以是中文或英文（旁白、主持人、Jim Fan、嘉宾等）
4. **文本归属**：标记后的所有文本归属该角色，直到下一个角色标记

## 音色配置

### 指定方式

直接用中文名指定音色，skill 会自动匹配 ListenHub 的 speakerId：

```
旁白用原野，主持人用晓曼，嘉宾用苏哲
```

## 工作流程

Skill 执行时会自动完成以下步骤：

1. **获取音色列表**：从 ListenHub API 获取所有中文音色
2. **匹配音色 ID**：根据你指定的中文名匹配对应的 speakerId
3. **解析脚本**：识别所有 `【角色】` 标记，按角色分段
4. **智能分段**：长文本自动按句子切分（每段最多 1500 字）
5. **批量生成**：调用 ListenHub API 生成所有音频片段
6. **自动合并**：使用 ffmpeg 按顺序合并为完整播客
7. **打开文件夹**：生成完成后自动打开输出目录

## 输出结果

### 文件结构

```
<脚本名>_ListenHub/
├── 001_旁白.mp3          # 分段音频
├── 002_主持人.mp3
├── 003_嘉宾.mp3

├── <脚本名>_完整版.mp3   # ← 合并后的完整播客
├── podcast_tts.py        # 生成脚本
└── filelist.txt          # 合并清单
```

### 音频规格

- **格式**：MP3
- **采样率**：32kHz
- **比特率**：128kbps
- **声道**：单声道 (Mono)
- **大小**：约 1MB/分钟

## 高级用法

### 多角色播客

支持任意数量的角色：

```
【旁白】
欢迎收听...

【主持人】
今天我们邀请到...

【嘉宾A】
大家好...

【嘉宾B】
很高兴...

【旁白】
感谢收听...
```

配置：
```
旁白用原野，主持人用晓曼，嘉宾A用苏哲，嘉宾B用国栋
```

### 长文本处理

Skill 会自动处理长文本：
- 单段超过 1500 字自动切分
- 按句号/问号/感叹号切分
- 保持句子完整性
- 合并时无缝衔接

### 错误处理

- **API 限流**：自动等待并重试
- **网络错误**：指数退避重试（最多 3 次）
- **音色不存在**：提示可用音色列表
- **脚本格式错误**：给出修正建议

## 注意事项

### API 配额

- ListenHub 有速率限制（400 次/窗口）
- 长播客可能需要几分钟生成
- 生成过程中会显示进度

### 文件大小

- 完整播客文件可能较大（约 1MB/分钟）
- 30 分钟播客约 25-30 MB
- 确保有足够磁盘空间

### 音色一致性

- 同一角色在整个播客中使用同一音色
- 避免频繁切换角色（影响听感）
- 建议主要角色不超过 3-4 个

### 标记规范

- 必须使用中文方括号 `【】`
- 角色标记独占一行
- 标记前后可以有空行
- 角色名不要包含特殊字符

## 故障排查

### 音色匹配失败

**问题**：提示"音色不存在"

**解决**：
1. 检查音色名是否正确（区分大小写）
2. 查看 skill 输出的可用音色列表
3. 使用推荐的常用音色

### 脚本解析失败

**问题**：提示"脚本为空或格式错误"

**解决**：
1. 检查是否使用了中文方括号 `【】`
2. 确保角色标记独占一行
3. 检查文件编码是否为 UTF-8

### 合并失败

**问题**：分段生成成功但合并失败

**解决**：
1. 检查是否安装了 ffmpeg：`ffmpeg -version`
2. 安装 ffmpeg：`brew install ffmpeg` (macOS)
3. 手动使用分段音频文件

### API 调用失败

**问题**：提示 API 错误

**解决**：
1. 检查网络连接
2. 确认 API Key 有效
3. 查看是否超出配额限制

## 技术细节

### API 配置

- **Endpoint**: `https://api.listenhub.ai/openapi/v1/tts`
- **认证**: Bearer Token
- **请求格式**: `{"input": "文本", "voice": "音色ID"}`
- **响应格式**: 直接返回 `audio/mpeg` 二进制

### 分段策略

- 单段最大：1500 字
- 切分规则：按句号/问号/感叹号
- 保持完整：不在句子中间切分
- 强制切分：单句超长时按字符切分

### 合并方法

使用 ffmpeg concat demuxer：
```bash
ffmpeg -f concat -safe 0 -i filelist.txt -c copy output.mp3
```

- 无需重新编码（`-c copy`）
- 保持原始音质
- 快速合并
