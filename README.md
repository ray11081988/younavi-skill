## 当前 skill

以下 Skill 来自 [YouNavi 玩法墙](https://younavi.me/playwall) 中 YouNavi 团队自研的部分，按场景分类：

### 知识和记忆管理

- **[Navi 每日记忆整理](<navi-memory-weaver/SKILL.md>)**（`navi-memory-weaver`）— 每日自动从多源数据（会议录音、工作IM聊天记录、本地文件、Navi对话、网页）中提取关键信息，增量编织到全局记忆中。灵感源自 Claude Code 的 Auto Dream 机制——让 AI 在每天结束时像人做梦一样，把当日碎片化经历整合进长期记忆。
- **[将视频内容变成图文笔记](<navi-video-explain/SKILL.md>)**（`navi-video-explain`）— 输入视频链接或本地视频文件，智能截取关键帧，结合视频内容和用户记忆偏好输出个性化图文讲解。支持自动转写、关键帧选择、要点提炼，将视频内容转化为结构化的图文笔记。来自 YouNavi 产品设计师 @CHA499

### 销售咨询

- **[人脉雷达](<connection-radar/SKILL.md>)**（`connection-radar`）— 从你的全局记忆、常用人名、历史录音和会议记录中找回目标人物、梳理现有关系路径，必要时用公开网页核实身份，并给出最直接的下一步和联系话术。适合只记得模糊线索、想找某个人，或想知道"谁能帮忙引荐"时使用。来自 YouNavi 产品运营 @泉此方
- **[客户雷达](<bd-account-radar/SKILL.md>)**（`bd-account-radar`）— 围绕"客户是谁、为什么现在联系、该找谁、如何触达"研究目标企业，综合内部交流、历史会议、现有人脉与公开网页（可选接入天眼查增强核验），给出 BD 判断、切入对象、触达路径和可直接发送的话术。适合要研究某家公司、判断是否值得跟进或准备陌生拜访时使用。来自 YouNavi 产品运营 @泉此方
- **[机会雷达](<opportunity-radar/SKILL.md>)**（`opportunity-radar`）— 从你的业务需求出发，结合 YouNavi 私人上下文和可追溯的公开网页证据，发现并筛选潜在客户、渠道或合作伙伴，输出 3–5 个值得深入核验的候选。适合还没有明确目标、只描述想找什么类型客户或合作方时使用。来自 YouNavi 产品运营 @泉此方

### 人力资源与组织发展

- **[Navi 招聘面试流程助手](<interview-pipeline/SKILL.md>)**（`interview-pipeline`）— 通用招聘流程 Harness——以飞书多维表格为主控台，完成简历入表、候选人评分、约面、面试提问draft、转写面试录音、候选人评价、面试内容复盘和多轮状态流转。来自 YouNavi 产品设计师 @CHA499

### 教育培训

- **[Navi 志愿填报教练](<navi-volunteer-fill/SKILL.md>)**（`navi-volunteer-fill`）— 不直接回答"选 A 还是 B"，而是搭建"短期选择"与"长期可塑性"之间的分析框架。用数据驱动的问题挑战你的假设，提取隐藏前提，输出关键追问清单，推动你在高考志愿填报中做出自主决策。来自 YouNavi 产品运营 @泉此方

### 内容创作

- **[宣讲演示Slides 制作](<YouNavi-Proposal Deck/SKILL.md>)**（`YouNavi-Proposal Deck`）— 制作精美的横向翻页宣讲演示Slides。适合产品分享、发布会演示、路线图展示和团队叙事。内置多种版式和组件，支持 html 展示和PDF 导出。来自 YouNavi 产品设计师 @CHA499
- **[生成 AI 播客](<podcast-tts/SKILL.md>)**（`podcast-tts`）— 可在 YouNavi 生成播客脚本文本内容后，指定角色的音色配置，并使用 ListenHub API 批量生成 TTS 音频文件、最终组合为完整的播客音频。来自 YouNavi 产品经理、播客“AI智识录”制作人 @Ray
- **[Logo 变插图](<draw-with-your-logo/SKILL.md>)**（`draw-with-your-logo`）— 把你的产品 Logo 提炼成品牌角色，生成带该角色的手绘风格的配图。支持角色设定图、shot list 和手绘插图风格，让 Logo 真正参与到文章内容中，而不只是贴在角落。 来自 YouNavi 产品运营 @泉此方
