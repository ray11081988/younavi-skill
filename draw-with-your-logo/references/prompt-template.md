# 生图提示词模板

## 角色设定图

```text
Create one clean character design sheet derived from the user-provided logo.

Use the uploaded logo as the identity source. Preserve these recognition anchors:
{轮廓 / 字母或符号 / 主色 / 独特部件}

Characterization:
{角色化路径、眼睛、四肢、比例、性格}

Show six separated poses on a pure white background:
front idle / walking or running / operating the signature element / thinking / connecting or repairing / finishing or celebrating.

Keep the same silhouette, proportions, colors, letters, symbols, eyes, and limbs in every pose. Use minimalist black hand-drawn line art and sparse brand-color accents. Add only short Chinese pose labels. No scene, no poster title, no cute mascot rendering, no gradients, no shadows, no extra characters.
```

## 正文配图

```text
Generate one standalone 16:9 horizontal Chinese article illustration.

Identity references:
Use the uploaded original logo and approved character sheet. Preserve exactly these 2-4 recognition anchors:
{识别锚点}

Character continuity:
{固定轮廓、比例、颜色、字母或符号、标志性部件状态规则}

Visual style:
Pure white background. Minimalist black hand-drawn line art with slightly wobbly pen lines. Lots of empty space. Sparse handwritten Chinese annotations using only colors sampled from the logo. Clean, clever, slightly absurd product-sketch feeling. No gradients, shadows, paper texture, commercial mascot poster, children's illustration, PPT infographic, formal flowchart, realistic UI, or complex background.

Theme:
{配图主题}

Core idea:
{核心意思}

Composition:
{角色位置、核心动作、主要物件与信息流}

Chinese labels:
{3-8 个短标注}

Constraints:
The logo-derived character must perform the core conceptual action. Do not paste the logo in a corner. Do not duplicate, remove, recolor, or misspell identity anchors. One image explains one structure. Keep at least 35% blank white space. Do not place a type title in the top-left. Invent a fresh visual metaphor for this article.
```

## 修复角色漂移

```text
Edit only the logo-derived character using the original uploaded logo and approved character sheet. Restore the canonical silhouette, proportions, brand colors, letterforms, symbols, eyes, limbs, and signature-element state. Preserve the composition, labels, and all unrelated objects.
```
